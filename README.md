# Cubo-2x2x2
Repositóro dedicado ao projeto cubo 2x2x2 em C++

Como rodar o Projeto:
    Rodamos no terminal:
        cd build
        cmake --build .
        .\meucubo.exe

Quando trocar de computador, faça:
Remove-Item -Recurse -Force build
mkdir build
cd build

e depois configura dnv:
& "C:\Qt\Tools\CMake_64\bin\cmake.exe" ..
